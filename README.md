# 🧭 بوصلة الأستاذ (الإصدار v4.4) — نظام الأندرويد والآيفون (iOS PWA)

**بوصلة الأستاذ** هو السجل الإلكتروني التربوي الشامل المصمّم خصيصاً للمعلمين والمدرسين وفق ضوابط ومعادلات **وزارة التربية العراقية**، متوفر بنسختين متطابقتين 100%:
1. **نسخة الأندرويد الأصلية (Android Kotlin / Jetpack Compose)** داخل مجلد `app/`.
2. **نسخة الآيفون والآيباد (iOS Web App / PWA)** الجاهزة في المجلد الرئيسي (`index.html` و `bousalat_alustadh_iphone.html`) وداخل مجلد `github_iphone_package/`.

---

## 📱 تشغيل وتثبيت نسخة الآيفون عبر GitHub Pages

جميع ملفات تطبيق الآيفون موضوعة في **المجلد الرئيسي للمستودع (Root)** بحيث يعمل التطبيق تلقائياً فور تفعيل **GitHub Pages**:

- `index.html` — ملف التطبيق الرئيسي الكامل (v4.4).
- `bousalat_alustadh_iphone.html` — نسخة مطابقة 100% من التطبيق.
- `manifest.json` — إعدادات التثبيت بملء الشاشة على نظام iOS.
- `sw.js` — مشغّل العمل بدون إنترنت (Offline Service Worker).
- `apple-touch-icon.png` / `icon-192.png` / `icon-512.png` — الأيقونات الرسمية للتطبيق.

### خطوات تفعيل رابط الآيفون في GitHub:
1. افتح مستودعك في **GitHub** واذهب إلى تبويب **Settings** (الإعدادات).
2. من القائمة الجانبية اليسرى اختر **Pages**.
3. تحت قسم **Build and deployment** -> **Branch**، اختر الفرع **`main`** والمجلد **`/ (root)`** ثم اضغط **Save**.
4. خلال دقيقة واحدة، سيعمل رابط تطبيق الآيفون الرسمي:
   `https://<USERNAME>.github.io/<REPO_NAME>/`
